## 肥鱼桌面控制中心 v0.1.0（发布候选）

基于现有 NapCat + OneBot QQ AI 机器人核心的**图形化管理桌面端**。不重写机器人业务逻辑，只读取/写入其真实配置文件、启停进程、展示真实用量数据。

### 下载

| 文件 | 说明 |
| --- | --- |
| `肥鱼桌面控制中心-0.1.0-win-x64.exe` | **Windows x64 NSIS 安装包**（约 110 MB）。图形化安装，可选安装目录，带开始菜单快捷方式与卸载程序。 |

安装后首次启动会在左下角提示选择**机器人目录**（即含 `ai_bridge.js` 的项目根）。程序会自动探测常见位置；探测不到时可手动指定。

### 功能

- **总览** — 机器人进程状态、今日请求数（成功/失败）
- **机器人运行** — 启停 AI 桥 / NapCat，查看进程与端口
- **API 与模型** — 多 Provider 注册表（增删改查 / 默认 / 协议级连通测试 / 差异预览后应用）、凭据安全状态与加密迁移
- **人格设置** — 人格模板库（新建 / 编辑 / 复制 / 重命名 / 行级差异预览 / 应用前自动备份），与运行中的人格配置分离
- **用量明细** — 时间范围 + Provider / 模型 / 状态筛选、耗时统计、CSV 导出、费用估算（支持历史价格，未定价显示「未定价」）
- **日志** — 机器人日志尾部与搜索（展示前自动脱敏）
- **导入导出** — 配置导入导出（默认不含密钥）、差异预览、应用前自动备份

### 数据来源

用量明细优先读取机器人本地真实记录 `<机器人目录>/memory/usage/YYYY-MM-DD.jsonl`，本地无文件时才回退运行中机器人的 `GET /api/usage`。两者都不可用时显示空状态并标注来源，**不做任何模拟数字**。费用为**估算值**，非服务商实际账单。

### 安全说明

- 渲染进程只能通过固定通道列表调用 IPC，逐通道参数校验；`contextIsolation: true` / `nodeIntegration: false`
- `SECRET_READ` 只返回密钥掩码，不回传明文
- 桌面侧多 Provider 密钥可用 Windows 系统凭据（DPAPI）加密存储，迁移会先备份明文、加密写入后回读校验、失败自动回滚
- 机器人自身的 `secrets.json` 保持明文（机器人进程独立运行、需要明文调用 API），不在本次加密范围
- 日志、导出、错误信息统一脱敏（密钥 / 本机路径 / 内部组件名）
