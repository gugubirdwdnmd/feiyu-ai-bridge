## 肥鱼桌面控制中心 v1.1.0（Windows x64）

继 v1.0.0 之后的功能版本，新增**主题工坊**。不重写机器人业务逻辑，只在桌面端增加外观自定义能力。

### 下载

| 文件 | 说明 |
| --- | --- |
| `feiyu-desktop-control-center-1.1.0-win-x64.exe` | **Windows x64 NSIS 安装包**（约 110 MB）。图形化安装，可选安装目录，带开始菜单快捷方式与卸载程序。 |
| `feiyu-desktop-control-center-1.1.0-portable.exe` | **便携版单文件**，免安装。 |

### v1.1.0 新增：主题工坊

导航新增「主题工坊」页面，可自定义整个界面的外观：

- **6 套配色预设** —— 深海 / 珊瑚礁 / 极光 / 樱花 / 抹茶 / 墨夜，各含背景色与两个强调色
- **自定义调色盘** —— 可改背景色与两个强调色，其余界面颜色按亮度自动推算，浅色主题下正文保持可读
- **4 种背景动画** —— 无 / 气泡上浮 / 极光漂移 / 条纹滚动，速度可调 0.3~2.5
- **外观参数** —— 圆角 4~28px、毛玻璃模糊 0~30px
- **导入导出** —— 主题 JSON 复制粘贴；导入先校验，**非法 JSON 不改动当前主题**

主题只写入 `%APPDATA%\feiyu-desktop-control-center\theme.json`，与机器人配置、密钥、机器人目录**完全分离**。

### v1.0.0 已有的能力

### 数据来源

用量明细优先读取机器人本地真实记录 `<机器人目录>/memory/usage/YYYY-MM-DD.jsonl`，本地无文件时才回退运行中机器人的 `GET /api/usage`。两者都不可用时显示空状态并标注来源，**不做任何模拟数字**。费用为**估算值**，非服务商实际账单。

### 安全说明

- 渲染进程只能通过固定通道列表调用 IPC，逐通道参数校验；`contextIsolation: true` / `nodeIntegration: false`
- `SECRET_READ` 只返回密钥掩码，不回传明文
- 桌面侧多 Provider 密钥可用 Windows 系统凭据（DPAPI）加密存储，迁移会先备份明文、加密写入后回读校验、失败自动回滚
- 机器人自身的 `secrets.json` 保持明文（机器人进程独立运行、需要明文调用 API），不在加密范围
- 主题文件不含路径、密钥或任何用户数据；读取时做白名单校验，损坏/非法时回退默认主题且不阻塞启动
- 日志、导出、错误信息统一脱敏（密钥 / 本机路径 / 内部组件名）

### 已知限制

- **未做代码签名**，Windows SmartScreen 可能提示「未知发布者」，需在「更多信息 → 仍要运行」中选择信任
- **图形化安装向导的逐页人工验收未完成** —— 验证机器处于锁屏状态，界面能渲染但收不到鼠标输入。已用自动化脚本做等价的程序化点击验收，但人工视觉走查与动画观感仍需在解锁环境下补做
- 卸载后若安装目录残留空目录，重新安装会失败（需先删除该空目录）
- 切换 Provider 后需重启 AI 桥才生效（机器人核心无热切换，界面已注明）
- 应用图标为 v1.1.0 新增的肥鱼形象；**窗口标题栏图标在部分 Windows 版本上可能仍显示系统默认**，不影响功能
